HOW TO USE

이 페이지 사용법

프롬프트는 강의 순서대로 이어져 있어요. 앞 단계의 결과가 다음 단계의 재료가 됩니다.

📄

원본 프롬프트

워크북 원문 그대로입니다. 노란색 부분을 내 정보로 바꿔서 사용하세요.

✍️

직접 입력 프롬프트

[      ] 빈칸을 눌러 바로 입력하세요. 같은 항목은 자동으로 함께 채워집니다.

🎲

예시내용 넣기

가상 대학생 20명의 예시 중 하나가 무작위로 들어갑니다. 누를 때마다 다른 예시가 나와요.

⧉

프롬프트 복사하기

초록 버튼을 누르면 복사되고 프롬프트 복사완료로 바뀝니다. AI 채팅창에 붙여넣으세요.

실습 5원칙

  1. 대괄호 바꾸기 [대괄호] 안의 내용을 내 정보로 바꾸고, 대괄호는 지운 뒤 입력합니다. 예시 문구는 참고만 하세요.
  2. 결과는 붙여넣어 이어가기 다음 단계로 넘어갈 때는 앞 단계 결과를 복사해 붙여넣기 칸에 넣습니다.
  3. 새 채팅에서 시작 프롬프트마다 새 채팅에서 시작하면 결과가 안정적입니다. (P3-1처럼 대화형은 같은 채팅에서 계속 답합니다.)
  4. 개인정보는 넣지 않기 실명·학번·전화번호·주소는 넣지 않습니다. 공개하고 싶지 않은 경험은 "가상 인물"로 바꾸어 실습해도 됩니다.
  5. 최종 판단은 나 AI가 쓴 경험·수치·출처는 반드시 내가 확인하고, 최종 문장은 내가 고릅니다.

120분 실습 흐름

단계를 누르면 해당 실습으로 바로 이동합니다.

＋🛠️
부록 1 · 언제든지

결과가 마음에 들지 않을 때 쓰는 보정 프롬프트

사용법 AI 답변이 아쉬울 때 같은 채팅창에 이어서 붙여넣으세요.

부록 2 · 도구별 실습 팁

ChatGPT③ 대화형 인터뷰, ⑦ 이미지 생성

대화가 길어지면 결과만 복사해 새 채팅에서 이어가기. 캔버스에서 HTML 미리보기가 가능합니다.

Google Gemini⑤ 기획서 작성, ⑦ 캔버스 웹페이지·이미지 생성

Google 계정 로그인 필요. 웹페이지는 "캔버스"를 켜고 P7-C2를 입력하면 미리보기와 코드를 함께 볼 수 있습니다.

Claude⑥ 첨삭, ⑦ HTML 포스터·카드뉴스

긴 글을 평가하고 표로 정리하는 데 강합니다. HTML 결과는 미리보기 화면으로 바로 확인합니다.

Perplexity Pro④ 근거 조사, 출처 재검증

답변 속 번호 출처를 눌러 원문을 직접 확인합니다. 대화형 인터뷰(P3-1)는 다른 도구를 씁니다.

※ 무료 계정은 사용량 제한이 있을 수 있습니다. 한 도구가 막히면 다른 도구로 같은 프롬프트를 입력하세요.
